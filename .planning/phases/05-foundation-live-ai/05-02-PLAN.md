## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Widget → POST /api/chat | Untrusted JSON body (messages, conversationId, page context) from browser iframe |
| POST /api/chat → Anthropic API | Server-side only; API key never leaves server; lazy import keeps SDK out of cold-path bundle |
| POST /api/chat → DB | All queries use parameterized sql tagged template (Neon HTTP driver) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-02-01 | Spoofing | Visitor identity | mitigate | getOrCreateVisitor() uses HMAC-verified cookie — already in place, preserved |
| T-05-02-02 | Tampering | messages[] input (prompt injection) | mitigate | Zod validates structure (id, role, parts with text max 4000); each part text is bounded; passes to convertToModelMessages server-side only |
| T-05-02-03 | Repudiation | Token usage accounting | mitigate | reserveTokens() before stream; reconcileTokens() in onFinish + onAbort; atomicity guaranteed by onAbort freeing reservation |
| T-05-02-04 | Information Disclosure | @ai-sdk/anthropic lazy import | mitigate | D-08 enforced: import inside CHATBOT_ENABLED=1 branch only — SDK absent from bundle when flag is 0 |
| T-05-02-05 | Denial of Service | Unconstrained stream length | mitigate | maxOutputTokens: 1000 limits per-response tokens; spend cap (checkSpendCap) blocks globally; rate limits (visitor 20/600s, IP 60/600s) bound request rate |
| T-05-02-06 | Denial of Service | Orphaned token reservations | mitigate | abortSignal: request.signal passed to streamText; onAbort fires on browser close and calls reconcileTokens(reservationId, 0) |
| T-05-02-07 | Elevation of Privilege | conversationId ownership bypass | mitigate | Ownership SQL SELECT + 404 guard preserved unchanged before streaming begins |
| T-05-02-08 | Tampering | SQL injection via message content | accept | sql tagged template uses parameterized queries throughout; Neon HTTP driver handles escaping |
</threat_model>
